# Third-party assets

## Football reference data

The exports in `data/big-five/` use Wikipedia squad tables (Wikipedia contributors, CC BY-SA 4.0) and Wikidata structured biographical data (CC0 1.0). Each record retains its source link and, when available, revision. The tables have been extracted and reorganized; game ratings have not been copied. See `data/big-five/README.md` and `manifest.json` for scope, attribution, licenses and missing fields. No photographs, crests or flag images are included.
