# Banderas del creador de cartas

SVG 4:3 de [flag-icons 7.3.2](https://github.com/lipis/flag-icons), distribuidos bajo licencia MIT. El texto completo de la licencia se conserva en `LICENSE`. `country.json` es el catálogo original del paquete. Los SVG se sirven localmente, sin solicitudes a un CDN mientras se usa la página.

`futin-card-data.js` utiliza los 249 códigos ISO del catálogo, con nombres en español proporcionados por `Intl.DisplayNames`, más las cuatro selecciones británicas (Inglaterra, Escocia, Gales e Irlanda del Norte). La bandera que se monta en la carta corresponde al mismo código elegido en el selector. No se ejecuta código del paquete descargado.

El archivo `.tgz` conserva la versión recibida del registro npm para trazabilidad. Solo se extrajeron los SVG de banderas y los archivos de catálogo y licencia.
